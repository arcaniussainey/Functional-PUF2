# PUF examples

Run examples from the repository root with `python examples/<name>.py`.

Recommended path:

1. `05_noob_pipeline_walkthrough.py` — line-by-line introduction to PUFs and the pipeline DSL.
2. `06_pipeline_composition.py` — standard, noisy, aged, XOR, and feed-forward pipelines.
3. `07_aging_puf.py` — explicit aging histories with `AgeRef` handles.
4. `08_feedforward_puf.py` — feed-forward Arbiter and feed-forward XOR PUF classes.
5. `09_statistics.py` — core PUF quality metrics.
6. `11_population_reliability_study.py` — a more realistic population-aging study.
7. `12_feedforward_aging_pipeline_experiment.py` — compiled feed-forward XOR pipeline.

`10_pypuf_wrapper.py` is optional and requires `pypuf`.
